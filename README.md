# 老师形象重构与透明抠图

面向教育海报的老师肖像处理技能：保留本人特征、按需换装、扩展到膝盖上缘、优化自然肤质，并检查透明抠图质量。

## 用 Codex 安装

将下面这段话发给 Codex：

```text
使用 $skill-installer 安装这个 GitHub 仓库里的技能：
https://github.com/whnxyouz/teacher-portrait-skill/tree/main/teacher-portrait
```

安装后在下一轮调用：

```text
使用 $teacher-portrait 处理上传的老师照片。保留本人特征和合适着装，扩到膝盖上缘，优化自然真人肤质，输出透明背景 PNG。
```

也可以下载仓库，将 `teacher-portrait` 文件夹放入自己的 Codex 用户技能目录，通常是 `~/.codex/skills/`。

## 用 GPT 网页版

打开 [网页版完整指令](web-instructions.md)，复制全文发送到新对话，再上传老师原照并说明本次要求。

也可以把这段话连同照片发给具备浏览能力的 GPT：

```text
请打开并完整读取下面链接中的老师肖像处理指令，将其作为本次图片编辑要求：
https://raw.githubusercontent.com/whnxyouz/teacher-portrait-skill/main/web-instructions.md
读取后先简要确认要求，再按这些要求处理我上传的照片。
如果打不开或无法获取全文，请告诉我，我会粘贴完整指令。
```

链接方式需要当前对话能访问网页。复制全文的方法更直接；仅发送仓库地址不会保证完整读取，也不会自动安装技能。换新对话时重新提供指令，或将其放入专用项目的项目指令。

### 常用请求

**标准处理**
> 保留这位老师的本人特征和现有合适着装，扩展至膝盖上缘，肤质自然，减少油光与碎片感，输出单人透明 PNG。

**只修肤质**
> 只优化面部肤质，保留五官、年龄、神态、服装、姿势和构图。控制油光，恢复自然连续的皮肤质感，保持透明背景。

**批量处理**
> 按上传顺序编号，先处理第一张样张。每人一个透明 PNG，合适着装保留，统一膝盖上缘构图。

## 处理原则

- 真实老师修肤质时保护本人辨识度，失败不自行换脸。
- 优先从原照处理，减少重复重绘造成的斑块和假纹理。
- “膝盖以上”是取景要求，长裤保持长裤。
- 分开检查皮肤碎片纹理与抠图残屑；透明通道不等于边缘已经干净。
- 人名与原照对应清楚，替换旧文件需有明确授权。
